# P5 Web UI (searcher experience) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the `/reply` page ("Find a meme for a message"): a message box, an editable reading of the message (chips), ranked results with explanations, axis facets and filters, degraded/unavailable/empty/error states, backed by the P4 endpoint and one new read-only vocabulary endpoint.

**Architecture:** One small backend endpoint serves the P1 taxonomy. In the frontend a thin `ReplyPage` composes presentational components around one stateful hook (`useMessageSearch`: a pure reducer plus an effectful shell for debounce, abort, sessionStorage) and a small `useTaxonomy` hook. All HTTP goes through the existing injected `MemesApi` interface (two new methods). Types come from the generated `all.d.ts`; nothing is hand-written that the generator produces.

**Tech Stack:** FastAPI + generated Pydantic models (backend), React 19 with the React Compiler babel plugin, React Router 7, Tailwind 4, vitest + Testing Library + user-event + jsdom (frontend). No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-02-meme-from-text/2026-10-08-p5-web-ui-design.md` (read it first). Inherited: the P4 endpoint and its addendum (handoff notes), `docs/superpowers/specs/2026-10-02-meme-from-text/2026-10-07-p4-retrieval-fusion-and-api-design.md`.

## Deviations from the spec text (decided while planning; the reviewers should know)

1. **"Show more" replays the exact request of the current list** (kept as `lastRequest` in state), not a rebuilt one: the server ties a cursor to the request fingerprint (text, profile, filters), and the first page of a plain Find has no `profile`; rebuilding the request with the returned profile would restart the list at page 1.
2. **A degraded original reading is never sent back as `profile`** (an empty degraded profile would be treated as an edited profile and rank nothing). Only an edited profile, or a non-degraded original, is sent; otherwise the server parses again (cached for 10 s when degraded).
3. **`AxisFacets` is a new component** (native checkbox groups with taxonomy labels, selected-but-zero-count values kept visible) instead of reusing `MultiSelectFacet`/`FacetSidebar`: those display the raw bucket value as the label and cannot show taxonomy labels. Spec decision 6 said "reuse the existing widget"; decision 10 (native labelled checkboxes in `fieldset`/`legend`) is the binding requirement.
4. **Abort handling lives in the hook**: the API client rethrows `AbortError`; `useMessageSearch` ignores aborted and superseded responses (spec decision 8 said the client swallows it; the effect is identical).
5. **sessionStorage also persists `originalProfile` and `submitted`**, so a restore re-runs retrieval only (one request) and "Reset to original reading" still works afterwards.

Create `Backend/app/services/meme_from_text_taxonomy.py`:

```python
"""The vocabulary payload for the web UI (P5): pure conversion of the loaded taxonomy."""
from functools import lru_cache

from taxonomy import load
from taxonomy.model import FREE_TEXT, LANGUAGES, Taxonomy


def taxonomy_payload(tax: Taxonomy) -> dict:
    axes = []
    for name, spec in tax.axes.items():
        axis: dict = {"name": name, "type": spec.type}
        if spec.max_values is not None:
            axis["maxValues"] = spec.max_values
        if spec.max_chars is not None:
            axis["maxChars"] = spec.max_chars
        if spec.type != FREE_TEXT:
            axis["values"] = [
                {"key": value.key, "definition": value.definition,
                 "labels": {lang: value.labels[lang] for lang in LANGUAGES}}
                for value in tax.values[name].values()
            ]
        axes.append(axis)
    return {"version": tax.version, "axes": axes}


@lru_cache(maxsize=1)
def cached_taxonomy_payload() -> dict:
    return taxonomy_payload(load())
```

```ts
async function readValidationMessages(response: Response): Promise<string[]> {
  try {

    return detail
      .map((item: unknown) => (typeof item === "string" ? item : (item as { msg?: unknown })?.msg))

    return []
```

```ts
/** Add a user-chosen value; the same object comes back when nothing changes (duplicate or axis full). */
export function addValue(profile: QueryProfile, axis: AxisName, key: string, maxValues: number): QueryProfile {
  const current = profile[axis]
  if (current.some((value) => value.key === key) || current.length >= maxValues) return profile
  return { ...profile, [axis]: [...current, { key, confidence: 1, source: "human" as const }] }
}

export function removeValue(profile: QueryProfile, axis: AxisName, key: string): QueryProfile {
  if (!profile[axis].some((value) => value.key === key)) return profile
  return { ...profile, [axis]: profile[axis].filter((value) => value.key !== key) }
}

export function setSituation(profile: QueryProfile, text: string): QueryProfile {
  const next = text.trim() === "" ? null : text.slice(0, SITUATION_LIMIT)
  if ((profile.situation ?? null) === next) return profile
  return { ...profile, situation: next, situationConfidence: null }
}

/** An edited profile is a reading the user vouches for: it is no longer degraded. */
export function toEditedProfile(profile: QueryProfile): QueryProfile {
  return { ...profile, degraded: false }
}

export function hasAnyValue(profile: QueryProfile): boolean {
  return Boolean(profile.situation) || profile.emotion.length + profile.stance.length + profile.topic.length + profile.tone.length > 0
}
```

```ts
import type { Filters, QueryProfile } from "./types"
import { AXES, EMPTY_FILTERS } from "./types"

const KEY = "reply.v1"

export type Saved = {
  text: string
  submitted: string | null
  originalProfile: QueryProfile | null
  editedProfile: QueryProfile | null
  filters: Filters
}

export function browserStorage(): Storage | null {
  try {
    return window.sessionStorage
  } catch {
    return null
  }
}

function cleanFilters(raw: unknown): Filters {
  const filters: Filters = { emotion: [], stance: [], topic: [], tone: [] }
  for (const axis of AXES) {
    const list = (raw as Record<string, unknown> | null)?.[axis]
    if (Array.isArray(list)) filters[axis] = list.filter((item): item is string => typeof item === "string")
  }
  return filters
}

export function loadSaved(storage: Storage | null): Saved | null {
  if (!storage) return null
  try {
    const raw = storage.getItem(KEY)
    if (!raw) return null
    const data = JSON.parse(raw)
    if (typeof data?.text !== "string") return null
    return {
      text: data.text,
      submitted: typeof data.submitted === "string" ? data.submitted : null,
      originalProfile: data.originalProfile ?? null,
      editedProfile: data.editedProfile ?? null,
      filters: data.filters ? cleanFilters(data.filters) : { ...EMPTY_FILTERS },
    }
  } catch {
    return null
  }
}

export function save(storage: Storage | null, saved: Saved): void {
  if (!storage) return
  try {
    storage.setItem(KEY, JSON.stringify(saved))
  } catch {
    // quota exceeded or storage blocked: the page works without persistence
  }
}
```

```ts
import { toRequestFilters } from "./filters"
import type { State } from "./messageSearchReducer"
import type { Filters, MemeFromTextRequest, QueryProfile } from "./types"
import { PAGE_SIZE } from "./types"

export type Mode = "find" | "refine" | "more"
export type Overrides = { editedProfile?: QueryProfile | null; filters?: Filters }

/** The profile worth sending: an edited one, or a usable (non-degraded) original. A degraded original is empty and would rank nothing. */
export function profileToSend(state: State, overrides: Overrides = {}): QueryProfile | null {
  const edited = overrides.editedProfile !== undefined ? overrides.editedProfile : state.editedProfile
  if (edited) return edited
  const original = state.originalProfile
  return original && !original.degraded ? original : null
}

export function buildRequest(state: State, mode: Mode, overrides: Overrides = {}): MemeFromTextRequest {
  if (mode === "find") return { text: state.text.trim(), limit: PAGE_SIZE }

  // "Show more" replays the exact request that produced the list: the server ties a cursor to the request.
  if (mode === "more" && state.lastRequest && state.nextCursor) {
    return { ...state.lastRequest, cursor: state.nextCursor }
  }

  const request: MemeFromTextRequest = { text: state.submitted ?? state.text.trim(), limit: PAGE_SIZE }
  const profile = profileToSend(state, overrides)
  if (profile) request.profile = profile
  const filters = toRequestFilters(overrides.filters ?? state.filters)
  if (filters) request.filters = filters
  return request
}
```

```ts
import type { Saved } from "./storage"
import type { Facet, Filters, MemeFromTextRequest, MemeFromTextResponse, MemeFromTextResult, QueryProfile, ResponseMeta } from "./types"
import { EMPTY_FILTERS } from "./types"
import type { Mode } from "./requests"

export type Status = "idle" | "reading" | "refining" | "ready" | "degraded" | "unavailable" | "error"
export type ErrorKind = "validation" | "failed"

export type State = {
  text: string
  submitted: string | null
  originalProfile: QueryProfile | null
  editedProfile: QueryProfile | null
  filters: Filters
  items: MemeFromTextResult[]
  facets: Facet[]
  nextCursor: string | null
  hasNext: boolean
  fallback: string
  meta: ResponseMeta | null
  /** The request body (without cursor) that produced the current list; "Show more" replays it. */
  lastRequest: MemeFromTextRequest | null
  status: Status
  error: ErrorKind | null
  loadingMore: boolean
}

export type Action =
  | { type: "text"; text: string }
  | { type: "findStarted"; submitted: string }
  | { type: "refineStarted" }
  | { type: "moreStarted" }
  | { type: "succeeded"; mode: Mode; response: MemeFromTextResponse; request: MemeFromTextRequest }
  | { type: "failed"; error: ErrorKind }
  | { type: "edited"; profile: QueryProfile }
  | { type: "resetEdit" }
  | { type: "filters"; filters: Filters }

export function initialState(saved: Saved | null): State {
  return {
    text: saved?.text ?? "",
    submitted: saved?.submitted ?? null,
    originalProfile: saved?.originalProfile ?? null,
    editedProfile: saved?.editedProfile ?? null,
    filters: saved?.filters ?? { ...EMPTY_FILTERS },
    items: [], facets: [], nextCursor: null, hasNext: false, fallback: "none", meta: null, lastRequest: null,
    status: saved?.submitted ? "refining" : "idle",
    error: null, loadingMore: false,
  }
}

export function statusFor(response: MemeFromTextResponse): Status {
  if (!response.meta.available) return "unavailable"
  return response.degraded ? "degraded" : "ready"
}

export function activeProfile(state: State): QueryProfile | null {
  return state.editedProfile ?? state.originalProfile
}

export function reducer(state: State, action: Action): State {
  switch (action.type) {
    case "text":
      return { ...state, text: action.text }
    case "findStarted":
      return {
        ...state, submitted: action.submitted, originalProfile: null, editedProfile: null, filters: { ...EMPTY_FILTERS },
        items: [], facets: [], nextCursor: null, hasNext: false, fallback: "none", meta: null, lastRequest: null,
        status: "reading", error: null, loadingMore: false,
      }
    case "refineStarted":
      return { ...state, status: "refining", error: null }
    case "moreStarted":
      return { ...state, loadingMore: true, error: null }
    case "succeeded": {
      const { response, mode, request } = action
      const { cursor: _cursor, ...requestWithoutCursor } = request
      void _cursor
      const common = {
        facets: response.facets ?? [], nextCursor: response.nextCursor ?? null, hasNext: response.hasNext,
        fallback: response.fallback, meta: response.meta, status: statusFor(response), error: null, loadingMore: false,
        lastRequest: requestWithoutCursor,
      }
      if (mode === "more") {
        // A stale cursor restarts the list server-side: its first item is then the one already shown first.
        const restarted = state.items.length > 0 && response.items.length > 0 && state.items[0].meme.id === response.items[0].meme.id
        return { ...state, ...common, items: restarted ? response.items : [...state.items, ...response.items] }
      }
      return {
        ...state, ...common, items: response.items,
        originalProfile: mode === "find" || state.originalProfile === null ? response.profile : state.originalProfile,
      }
    }
    case "failed":
      return { ...state, status: "error", error: action.error, loadingMore: false }
    case "edited":
      return { ...state, editedProfile: action.profile }
    case "resetEdit":
      return { ...state, editedProfile: null }
    case "filters":
      return { ...state, filters: action.filters }
  }
}
```

`src/reply/useMessageSearch.ts`:

```ts
import { useCallback, useEffect, useReducer, useRef, useState } from "react"
import type { MemesApi } from "../api/MemesApi"
import { MessageSearchValidationError, isAbortError } from "../api/errors"
import { activeProfile, initialState, reducer } from "./messageSearchReducer"
import { addValue, removeValue, setSituation, toEditedProfile } from "./profile"
import { buildRequest } from "./requests"
import type { Mode, Overrides } from "./requests"
import { browserStorage, loadSaved, save } from "./storage"
import type { AxisName, Filters, QueryProfile } from "./types"
import { DEBOUNCE_MS, EMPTY_FILTERS } from "./types"

type Options = { debounceMs?: number; storage?: Storage | null }

export function useMessageSearch(memesApi: MemesApi, options: Options = {}) {
  const debounceMs = options.debounceMs ?? DEBOUNCE_MS
  const [storage] = useState<Storage | null>(() => (options.storage === undefined ? browserStorage() : options.storage))
  const [saved] = useState(() => loadSaved(storage))
  const [state, dispatch] = useReducer(reducer, saved, initialState)

  const stateRef = useRef(state)
  const seqRef = useRef(0)
  const abortRef = useRef<AbortController | null>(null)
  const timerRef = useRef<ReturnType<typeof setTimeout> | null>(null)

  useEffect(() => {
    stateRef.current = state
  })

  const execute = useCallback(async (mode: Mode, overrides: Overrides = {}) => {
    const current = stateRef.current
    const request = buildRequest(current, mode, overrides)
    const seq = ++seqRef.current
    abortRef.current?.abort()
    const controller = new AbortController()
    abortRef.current = controller

    if (mode === "find") dispatch({ type: "findStarted", submitted: request.text })
    else if (mode === "refine") dispatch({ type: "refineStarted" })
    else dispatch({ type: "moreStarted" })

    try {
      const response = await memesApi.searchMemeFromText(request, controller.signal)
      if (seq !== seqRef.current) return
      dispatch({ type: "succeeded", mode, response, request })
    } catch (error) {
      if (isAbortError(error) || seq !== seqRef.current) return
      dispatch({ type: "failed", error: error instanceof MessageSearchValidationError ? "validation" : "failed" })
    }
  }, [memesApi])

  function cancelTimer() {
    if (timerRef.current) {
      clearTimeout(timerRef.current)
      timerRef.current = null
    }
  }

  // Restore: a saved search re-runs retrieval only (the saved reading is sent back). The dispatch happens after an
  // await so it is not a synchronous state update in the effect body.
  useEffect(() => {
    if (!saved?.submitted) return
    void Promise.resolve().then(() => execute("refine"))
  }, [saved, execute])

  useEffect(() => {
    save(storage, {
      text: state.text, submitted: state.submitted, originalProfile: state.originalProfile,
      editedProfile: state.editedProfile, filters: state.filters,
    })
  }, [storage, state.text, state.submitted, state.originalProfile, state.editedProfile, state.filters])

  useEffect(() => () => {
    if (timerRef.current) clearTimeout(timerRef.current)
    abortRef.current?.abort()
  }, [])

  function setText(text: string) {
    dispatch({ type: "text", text })
  }

  function find() {
    if (stateRef.current.text.trim() === "") return
    cancelTimer()
    void execute("find")
  }

  function editProfile(update: (profile: QueryProfile) => QueryProfile) {
    const current = stateRef.current
    const base = activeProfile(current)
    if (!base) return
    const updated = update(base)
    if (updated === base) return
    const next = toEditedProfile(updated)
    dispatch({ type: "edited", profile: next })
    cancelTimer()
    timerRef.current = setTimeout(() => {
      timerRef.current = null
      void execute("refine", { editedProfile: next })
    }, debounceMs)
  }

  function resetProfile() {
    if (!stateRef.current.editedProfile) return
    cancelTimer()
    dispatch({ type: "resetEdit" })
    void execute("refine", { editedProfile: null })
  }

  function setFilter(axis: AxisName, values: string[]) {
    const current = stateRef.current
    if (!current.submitted) return
    const filters: Filters = { ...current.filters, [axis]: values }
    cancelTimer()
    dispatch({ type: "filters", filters })
    void execute("refine", { filters })
  }

  function clearFilters() {
    const current = stateRef.current
    if (!current.submitted) return
    cancelTimer()
    dispatch({ type: "filters", filters: { ...EMPTY_FILTERS } })
    void execute("refine", { filters: { ...EMPTY_FILTERS } })
  }

  function loadMore() {
    const current = stateRef.current
    if (!current.hasNext || !current.nextCursor || current.loadingMore) return
    void execute("more")
  }

  return {
    state, activeProfile: activeProfile(state),
    setText, find, editProfile, resetProfile, setFilter, clearFilters, loadMore,
    helpers: { addValue, removeValue, setSituation },
  }
}
```

```ts
import { useEffect, useState } from "react"
import type { MemesApi } from "../api/MemesApi"
import type { TaxonomyResponse } from "./types"

/**
 * Loads the vocabulary once per mount. When a search response reports another taxonomy version
 * (`expectedVersion`), it loads again (the effect re-runs only when the mismatching version changes).
 */
export function useTaxonomy(memesApi: MemesApi, expectedVersion: number | null): TaxonomyResponse | null {
  const [taxonomy, setTaxonomy] = useState<TaxonomyResponse | null>(null)
  const refetchFor = taxonomy && expectedVersion !== null && taxonomy.version !== expectedVersion ? expectedVersion : null

  useEffect(() => {
    let cancelled = false
    memesApi.getTaxonomy().then(
      (loaded) => { if (!cancelled) setTaxonomy(loaded) },
      () => { /* the chips still render from their keys; only the picker is empty */ },
    )
    return () => { cancelled = true }
  }, [memesApi, refetchFor])

  return taxonomy
}
```

```tsx
import { useEffect, useId, useRef, useState } from "react"
import type { PickerOption } from "../../reply/taxonomy"

type Props = {
  axisLabel: string
  options: PickerOption[]
  disabled?: boolean
  onPick: (key: string) => void
}

export default function ValuePicker({ axisLabel, options, disabled = false, onPick }: Props) {
  const [open, setOpen] = useState(false)
  const [active, setActive] = useState(0)
  const buttonRef = useRef<HTMLButtonElement>(null)
  const listRef = useRef<HTMLUListElement>(null)
  const listId = useId()

  useEffect(() => {
    if (open) listRef.current?.focus()
  }, [open])

  function close() {
    setOpen(false)
    buttonRef.current?.focus()
  }

  function pick(key: string) {
    onPick(key)
    close()
  }

  function onKeyDown(e: React.KeyboardEvent<HTMLUListElement>) {
    if (e.key === "ArrowDown") {
      e.preventDefault()
      setActive((i) => Math.min(i + 1, options.length - 1))
    } else if (e.key === "ArrowUp") {
      e.preventDefault()
      setActive((i) => Math.max(i - 1, 0))
    } else if (e.key === "Enter") {
      e.preventDefault()
      const option = options[active]
      if (option) pick(option.key)
    } else if (e.key === "Escape") {
      e.preventDefault()
      close()
    }
  }

  return (
    <span className="relative inline-block">
      <button
        ref={buttonRef}
        type="button"
        disabled={disabled}
        aria-haspopup="listbox"
        aria-expanded={open}
        aria-controls={open ? listId : undefined}
        onClick={() => {
          setActive(0)
          setOpen((o) => !o)
        }}
        className="min-h-11 rounded-full border border-dashed px-3 text-sm text-blue-700 disabled:opacity-40"
      >
        + Add<span className="sr-only"> {axisLabel.toLowerCase()}</span>
      </button>
      {open && (
        <ul
          id={listId}
          ref={listRef}
          role="listbox"
          tabIndex={0}
          aria-label={`Add ${axisLabel.toLowerCase()}`}
          aria-activedescendant={options[active] ? `${listId}-${options[active].key}` : undefined}
          onKeyDown={onKeyDown}
          onBlur={(e) => {
            if (!e.currentTarget.contains(e.relatedTarget as Node | null)) setOpen(false)
          }}
          className="absolute z-10 mt-1 max-h-64 min-w-48 overflow-auto rounded-md border bg-white py-1 shadow-lg"
        >
          {options.length === 0 && <li className="px-3 py-2 text-sm text-gray-500">No more values</li>}
          {options.map((option, index) => (
            <li
              key={option.key}
              id={`${listId}-${option.key}`}
              role="option"
              aria-selected={index === active}
              title={option.definition}
              onMouseDown={(e) => e.preventDefault()}
              onClick={() => pick(option.key)}
              className={`cursor-pointer px-3 py-2 text-sm ${index === active ? "bg-blue-50" : ""}`}
            >
              {option.label}
            </li>
          ))}
        </ul>
      )}
    </span>
  )
}
```

```tsx
import { useEffect, useRef } from "react"
import type { PickerOption } from "../../reply/taxonomy"
import type { AxisName, QueryProfile } from "../../reply/types"
import ValuePicker from "./ValuePicker"

type Props = {
  axis: AxisName
  label: string
  values: QueryProfile["emotion"]
  labelOf: (key: string) => string
  options: PickerOption[]
  maxValues: number
  pickerDisabled?: boolean
  onAdd: (key: string) => void
  onRemove: (key: string) => void
}

export default function ChipGroup({ axis, label, values, labelOf, options, maxValues, pickerDisabled = false, onAdd, onRemove }: Props) {
  const groupRef = useRef<HTMLDivElement>(null)
  const pendingFocus = useRef<string | null>(null)

  // After a removal, focus moves to a neighbouring chip's remove button, or to the add button.
  useEffect(() => {
    const target = pendingFocus.current
    if (target === null) return
    pendingFocus.current = null
    const root = groupRef.current
    if (!root) return
    const selector = target === "" ? "[data-add-button] button" : `[data-chip-remove="${target}"]`
    const element = root.querySelector<HTMLElement>(selector) ?? root.querySelector<HTMLElement>("[data-add-button] button")
    element?.focus()
  })

  function remove(key: string, index: number) {
    const neighbour = values[index + 1] ?? values[index - 1]
    pendingFocus.current = neighbour ? neighbour.key : ""
    onRemove(key)
  }

  const chosen = new Set(values.map((value) => value.key))
  const available = options.filter((option) => !chosen.has(option.key))
  const full = values.length >= maxValues

  return (
    <div ref={groupRef} className="mb-3" data-axis={axis}>
      <div className="mb-1 text-sm font-medium text-gray-700">{label}</div>
      <ul aria-label={label} className="flex flex-wrap items-center gap-2">
        {values.length === 0 && <li className="text-sm text-gray-400">none</li>}
        {values.map((value, index) => (
          <li key={value.key} className="flex items-center gap-1 rounded-full bg-blue-100 py-1 pl-3 pr-1 text-sm">
            <span>{labelOf(value.key)}</span>
            <button
              type="button"
              data-chip-remove={value.key}
              aria-label={`Remove ${label.toLowerCase()}: ${labelOf(value.key)}`}
              onClick={() => remove(value.key, index)}
              className="flex h-11 w-11 items-center justify-center rounded-full hover:bg-blue-200"
            >
              <span aria-hidden="true">×</span>
            </button>
          </li>
        ))}
        {!full && (
          <li data-add-button>
            <ValuePicker axisLabel={label} options={available} disabled={pickerDisabled} onPick={onAdd} />
          </li>
        )}
      </ul>
    </div>
  )
}
```

```tsx
}

function describe(axis: AxisExplanation, labelOf: Props["labelOf"]): string {
  if (axis.neutral) return "no value on this axis (neutral)"
  if (axis.axis === "situation") return "similar situation"
  if (axis.axis === "lexical") return "words from your message appear in this meme"

    .map((pair) => {

    })
    .join(", ")
}
```

```tsx
type Props = {
```

```tsx
  selected: Filters
  taxonomy: TaxonomyResponse | null
  onChange: (axis: (typeof AXES)[number], values: string[]) => void
  onClear: () => void
}

export default function AxisFacets({ facets, selected, taxonomy, onChange, onClear }: Props) {
  return (
    <div>
      {hasFilters(selected) && (
        <button type="button" onClick={onClear} className="mb-3 min-h-11 text-sm text-blue-600 hover:underline">
          Clear filters
        </button>
      )}
      {AXES.map((axis) => {
        const buckets = facets.find((facet) => facet.name === axis)?.buckets ?? []
        const counts = new Map(buckets.map((bucket) => [bucket.value, bucket.count]))
        // A selected value that the filtered results no longer contain stays visible (count 0) so it can be unchecked.
        for (const value of selected[axis]) if (!counts.has(value)) counts.set(value, 0)
        const rows = [...counts.entries()].sort((a, b) => b[1] - a[1] || a[0].localeCompare(b[0]))
        if (rows.length === 0) return null
        return (
          <fieldset key={axis} className="mb-4">
            <legend className="mb-1 font-medium">{AXIS_LABELS[axis]}</legend>
            {rows.map(([value, count]) => {
              const checked = selected[axis].includes(value)
              return (
                <label key={value} className="flex min-h-11 items-center gap-2 text-sm">
                  <input
                    type="checkbox"
                    checked={checked}
                    onChange={() =>
                      onChange(axis, checked ? selected[axis].filter((v) => v !== value) : [...selected[axis], value])
                    }
                  />
                  <span>{`${labelFor(taxonomy, axis, value)} (${count})`}</span>
                </label>
              )
            })}
          </fieldset>
        )
      })}
    </div>
  )
```

```tsx
import type { ErrorKind, Status } from "../../reply/messageSearchReducer"

type Props = {
  status: Status
  fallback: string
  error: ErrorKind | null
  onRetry: () => void
}

const REASONS: Record<string, string> = {
  unavailable: "the language model is not reachable",
  timeout: "the language model took too long",
  invalid_output: "the language model gave an unusable answer",
  breaker_open: "the language model was temporarily skipped after repeated failures",
  embed_unavailable: "the similarity model is not reachable",
  empty_input: "there was nothing to read",
}

function reasonsFor(fallback: string): string {
  return fallback
    .split("+")
    .map((part) => REASONS[part])
    .filter(Boolean)
    .join("; ")
}

export default function StatusBanner({ status, fallback, error, onRetry }: Props) {
  if (status === "reading") {
    return <p role="status" className="rounded-md bg-blue-50 p-3">Reading your message…</p>
  }
  if (status === "degraded") {
    const reasons = reasonsFor(fallback)
    return (
      <div role="status" className="rounded-md bg-yellow-50 p-3">
        <strong>Limited understanding.</strong> A simpler match was used{reasons ? `: ${reasons}` : ""}. Results may be less precise.
      </div>
    )
  }
  if (status === "unavailable") {
    return <p role="status" className="rounded-md bg-gray-100 p-3">Message search isn't available in this environment.</p>
  }
  if (status === "error") {
    return (
      <div role="alert" className="flex flex-wrap items-center gap-3 rounded-md bg-red-50 p-3">
        <span>
          {error === "validation"
            ? "The search request was rejected. Check the message and your edits, then try again."
            : "Something went wrong while searching. Please try again."}
        </span>
        <button type="button" onClick={onRetry} className="min-h-11 rounded border px-3">Try again</button>
      </div>
    )
  }
  return null
}
```
