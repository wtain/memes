# Home Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the `/` redirect with a Home page: search hero with verified example chips and per-browser last searches, a Recently added rail, a Trending rail and a Reply shortcut.

**Architecture:** Frontend only. A `src/home/` folder holds pure helpers (`recentSearches`, `examples`), one data hook (`useHomeFeeds`) and presentational pieces (`SearchHero`, `Rail`, `ReplyShortcut`); `src/pages/HomePage.tsx` composes them. Everything uses existing READER endpoints through `MemesApi.searchMemes` and `getTrendingMemes`.

**Tech Stack:** React, TypeScript, react-router-dom, Tailwind 4 semantic tokens, `src/ui/*`, vitest + testing-library, pnpm.

**Spec:** `docs/superpowers/specs/2026-11-19-home-page-design.md` (read "Decisions (owner-approved 2026-11-19)" and its addendum first). Design system: `docs/superpowers/specs/2026-11-18-design-system-and-card-redesign.md`.

## Global Constraints

- Work only inside `Frontend/memes-frontend/` (paths relative to it unless prefixed `docs/`). `Backend/`, `backend_api.md`, `shared/`, `AndroidClient/`, `src/types/generated/`, `package.json`, `pnpm-lock.yaml` are not touched (empty `git diff`).
- No new dependency; `node_modules` is installed, do not reinstall. No dev server needed; do not bind ports 5173-5175, 5190, 8081-8083.
- Edit with the Edit/Write tools, never PowerShell Get/Set-Content.
- React Compiler ESLint rules and StrictMode: effects survive a double mount, refs only in handlers and effects, no `useMemo`/`useCallback` added for performance.
- Semantic tokens only (`bg-surface`, `text-fg-muted`), spacing multiples of 4 px, motion only under `motion-safe:`, no raw colours.
- Home never calls a DEV_ONLY endpoint (`/api/history`, `/api/diagnostics/statistics`) and never a new endpoint.
- Rail card widths `w-40` below `sm`, `w-44` from `sm`; max 12 cards per rail; search input 48 px high, font 16 px.
- localStorage key `home.recentSearches.v1` (max 5, 64 chars, case-insensitive dedupe); sessionStorage key `home.examples.v1` (max 3 short strings); every storage access in try/catch.

## Review Focus

- `localStorage`/`sessionStorage` that throws or holds garbage (non-JSON, wrong shape, 1000 entries): Home renders, no row, no error (Tasks 3, 5).
- Search text with `&`, spaces, `#`, unicode or only spaces: URL is `encodeURIComponent`-encoded; blank goes to `/search` (Task 7).
- Recent feed containing flagged memes, or fewer than 12 after filtering: flagged never shown (Task 4).
- Trending items all duplicating Recent, or exactly 2 left: rail hidden, no message (Task 4, 9).
- Backend down: both rails error independently, box still navigates; double mount issues each request once (Tasks 4, 9).
