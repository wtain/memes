# Ingestion Tier B Cluster Cap (Stopgap) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `IngestionService.list_clusters` never returns a cluster larger than 60 members; the frontend shows what was capped.

**Architecture:** In the existing cluster-assembly loop, after `_sort_key`/`min_distance` are computed from the full group (so the cursor is unaffected), keep only the 60 members with the tightest incident edge and the edges among them; add `total_members` (the uncapped count) to the response. `ClusterRow` renders a "Showing 60 of N" line when `total_members` exceeds `members.length`.

**Tech Stack:** FastAPI + SQLAlchemy service layer, Dynaconf-free (constant), pytest; React + Vitest for the one frontend line; hand-written JSON Schema → generated TS/Kotlin.

**Spec:** `docs/superpowers/specs/2026-09-10-ingestion-tier-b-cluster-cap-stopgap-design.md`

## Global Constraints

- **`CLUSTER_MEMBER_CAP = 60`** — module-level constant in `ingestion_service.py`.
- The cap must not change `_sort_key`, `min_distance`, the cursor, `next_cursor`, `has_next`, or the cluster ordering — those are computed from the **uncapped** group/`group_edges` before the cap is applied.
- Tier A is unaffected in practice (no cluster approaches 60) and must stay behavior-identical: when `total_members <= 60`, `members`/`edges` are returned whole and `total_members == len(members)`.
- **Accepted cost (from the spec):** members capped off the giant group stay unreviewable → `ingest_promote` keeps blocking them and the run can't complete until the per-image review spec ships. This is deliberate.
- `cd Backend && pytest` run on its own — never combined with other roots. Integration tests need `DATABASE_URL="postgresql+asyncpg://ocr:ocr@localhost:5432/ocrdb_test"` on the command line.
- Generated files (`Frontend/memes-frontend/src/types/generated/all.d.ts`, Android `Models.kt`) regenerated by the real generators and committed in the same task as the schema change (CI diffs them).
- `backend_api.md` updated in the task that changes the endpoint.

- [ ] **Step 3: Implement the constant + helper**

In `Backend/app/services/ingestion_service.py`, near `_split_params` (module level):

```python
CLUSTER_MEMBER_CAP = 60


def _members_by_tightest_edge(group, group_edges) -> list[str]:
    """The group's member ids (as strings) ordered by the tightest edge each sits on --
    used to keep the `CLUSTER_MEMBER_CAP` most-relevant members when a group is oversized.
    Members with no incident edge sort last, by id string."""
    ids = [str(m) for m in group]
    best: dict[str, float] = {i: float("inf") for i in ids}
    for e in group_edges:
        d = e["distance"]
        for side in (e["image_id1"], e["image_id2"]):
            if side in best and d < best[side]:
                best[side] = d
    return sorted(ids, key=lambda i: (best[i], i))
```

```python
            for gi, group in enumerate(groups):
                member_ids = {str(m) for m in group}
                group_edges = buckets[gi]
                min_distance = min((e["distance"] for e in group_edges), default=1.0)
```

Replace the body from `min_distance = ...` onward with:

```python
                min_distance = min((e["distance"] for e in group_edges), default=1.0)
                sort_key = (min_distance, min(member_ids))

                total_members = len(group)
                members = [member_info[m] for m in group]
                if total_members > CLUSTER_MEMBER_CAP:
                    keep = set(_members_by_tightest_edge(group, group_edges)[:CLUSTER_MEMBER_CAP])
                    members = [mi for mi in members if mi["image_id"] in keep]
                    group_edges = [e for e in group_edges
                                   if e["image_id1"] in keep and e["image_id2"] in keep]

                clusters.append({
                    "members": members,
                    "edges": group_edges,
                    "total_members": total_members,
                    "_sort_key": sort_key,
                })
```

`sort_key` / `min_distance` come from the **uncapped** `group_edges`, so `clusters.sort`, the cursor filter, `next_cursor`, and `has_next` (all below this loop, unchanged) see the same ordering as before.

```python
"""list_clusters caps an oversized cluster's members at CLUSTER_MEMBER_CAP while leaving the
cursor / ordering identical to the uncapped run. Requires a live PostgreSQL (see conftest)."""
import uuid

import pytest

from Backend.app.repositories.ingestion_repository import IngestionRepository
from Backend.app.services import ingestion_service as S
from Backend.app.services.ingestion_service import IngestionService, CLUSTER_MEMBER_CAP
from repository.batch_runs import BatchRunRepository
from Storage.models import Image, TmpDuplicates


async def _make_run(session):
    return await BatchRunRepository(session).create_run(kind="ingestion", trigger="manual", stage="tier_b_review")


async def _make_image(session, status, batch_id):
    img = Image(filename=f"{uuid.uuid4()}.jpg", status=status, ingestion_batch_id=batch_id)
    session.add(img); await session.flush(); return img.id


async def _make_pair(session, a, b, dist):
    session.add(TmpDuplicates(image_id1=min(a, b), image_id2=max(a, b), distance=dist, match_source="in_batch"))
    await session.flush()


@pytest.fixture
def no_split(monkeypatch):
    # one blob per component -> the star below stays a single oversized group
    monkeypatch.setattr("Backend.app.services.ingestion_service._split_params", lambda tier: None)


@pytest.mark.asyncio(loop_scope="session")
async def test_oversized_cluster_is_capped_and_reports_total(db_session, no_split):
    batch_id = await _make_run(db_session)
    hub = await _make_image(db_session, "pending", batch_id)
    spokes = [await _make_image(db_session, "pending", batch_id) for _ in range(CLUSTER_MEMBER_CAP + 20)]
    for i, s in enumerate(spokes):
        await _make_pair(db_session, hub, s, 0.10 + i * 0.0001)  # all in Tier B band, distinct

    service = IngestionService(IngestionRepository(db_session))
    page = await service.list_clusters("tier_b", batch_id=batch_id)

    assert len(page["items"]) == 1
    c = page["items"][0]
    assert c["total_members"] == CLUSTER_MEMBER_CAP + 21
    assert len(c["members"]) == CLUSTER_MEMBER_CAP
    kept = {m["image_id"] for m in c["members"]}
    assert all(e["image_id1"] in kept and e["image_id2"] in kept for e in c["edges"])
    # the hub sits on every edge (tightest) -> always kept
    assert str(hub) in kept


@pytest.mark.asyncio(loop_scope="session")
async def test_small_clusters_untouched(db_session, no_split):
    batch_id = await _make_run(db_session)
    a = await _make_image(db_session, "pending", batch_id)
    b = await _make_image(db_session, "pending", batch_id)
    await _make_pair(db_session, a, b, 0.12)

    service = IngestionService(IngestionRepository(db_session))
    page = await service.list_clusters("tier_b", batch_id=batch_id)

    c = page["items"][0]
    assert c["total_members"] == 2 == len(c["members"])
```
